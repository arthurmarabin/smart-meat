# Smart Meat Club

Smart Meat Club e um clube de assinatura de carne sul-americana refrigerada entregue em Orlando, Florida. O projeto existe para viabilizar o ritual do churrasco sul-americano com cortes tradicionais, origem confiavel e entrega em casa.

Este repo e a fundacao conceitual do projeto, gerada pelo Marabin Method v2.0.0 como piloto da Fase 4 da migracao v2.0. Ele organiza identidade, cliente, oferta, aquisicao, metricas e operacao inicial.
